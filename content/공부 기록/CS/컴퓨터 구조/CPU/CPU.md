CPU안의 구성은 다음과 같이 이루어져 있다.

[[ALU]] : 논리/산술 연산을 진행하는 역할( 3. Execution)
[[컨트롤 유닛]] : ALU가 진행할 연산을 해석해주는 역할( 2. Decode)
[[Register]] : ALU와 컨트롤 유닛이 사용할 데이터를 저장해두는 역할
[[버스 인터페이스]] : 입출력 버스와 데이터를 주고 받기 위한 매개체 역할
[[입출력버스]] ( 1. Fetch)

메모리에 있는 명령어들은
1. Fetch : 입출력 버스를 통해 CPU로 전송되고
2. 버스인터페이스를 통해 데이터를 받아내며
3. 레지스터에 저장되었다가
4. Decode : 컨트롤 유닛이 명령어를 해석하고
5. Execution : ALU가 연산을 진행한다.
