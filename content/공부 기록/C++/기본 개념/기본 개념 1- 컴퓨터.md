[[컴파일러]] : 컴퓨터가 이해할 수 있는 기계단위(중간언어)의 언어로 치환 시켜주는 것.
(코드 번역)
(실행 파일 생성)
코드 -> 중간 언어 -> 기계언어(바이너리)

4대 메모리 : 
[[CS/컴퓨터 구조/HDD]]- 하드디스크 (tb) - 파일과 관련된 저장
[[CS/컴퓨터 구조/메인 메모리/RAM]] - 램 (gb) - 현재 실행 중인 프로그램
[[CS/컴퓨터 구조/CPU/Cache]] - 캐시 (mb) - 주요 명령어를 저장해서, 다시 실행했을 때 복원해서 구동
[[CS/컴퓨터 구조/CPU/Register]] - 레지스터 (bit) - alu가 연산을 하기 전,후에 임시로 저장.
CPU -> [[CS/컴퓨터 구조/CPU/ALU]]

아래에서 위로 올라가는 순서로 ALU와 가까움 -  즉 연산속도가 점점 빨라짐. 
위로 올라갈 수록 용량이 큼.
