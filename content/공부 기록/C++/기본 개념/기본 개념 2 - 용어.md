피연산자 = 자료
자료는 반드시 메모리 공간 안에 저장을 해야한다.

정수, 실수 , 문자 , 논리=> 자료형

상수 , 변수 

---

상수 : 변하지 않는 숫자
-리터럴 상수 : 원래부터 상수 (R-value) (10, 'a')
-심볼릭 상수 : 프로그램에서 제공하는 특정 키워드 삽입으로 만들어서 사용하는 상수 (const)

변수 : 코드의 흐름에 따라 변하는 숫자

변수 이름 짓기 문법 : 
	1) 알파벳과 숫자로 구성 가능, 숫자가 맨 첫글자는 안됨
	2) 대문자와 소문자를 구분함.
	3) 기본 키워드로 변수 이름으로 지을 수 없음
	4) 변수 이름에 공백 . 특수문자 불가(언더바 제외)
	5) 같은 중괄호{} 안에서 같은 이름으로 재생성할 수 없다.

표기법 (관습적) : 
	의미없는 변수 : Dst, Src, Tmp -> Dest, Sour, Temp
	1. 헝가리안 : 변수 이름 앞에 자료형을 의미하는 특수 부호 또는 스펠링을 삽입 . 
		ex) int iTest = 5;
	2. 카멜 : 단어와 단어 사이를 대문자로 구분하는 방법
	3. 파스칼 : 단어의 첫 글자를 대문자로 구분하는 방법
	4. 언더바 : 단어와 단어 사이를 언더바로 구분하는 방법

선언과 초기화

선언 = 어떤 자료 타입으로 변수의 이름을 짓는 행위 이때 값은 메모리 값에 저장되지 않았음. (쓰레기 값이 차있는 형태)

초기화 = 메모리를 생성함과 동시에 프로그래머가 원하는 값으로 채워서 사용하는 행위 
선언 시점 1회만 사용 가능.
C언어 스타일은 -> int i = 0
C++ 언어 스타일은 -> int i(0)

---

컴퓨터 연산의 최소 단위 : 비트 bit
컴퓨터 저장의 최소 단위 : 바이트 byte = 8 bit
