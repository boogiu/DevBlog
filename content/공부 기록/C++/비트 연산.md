#이진법

1100 0011 => 128 + 64 + 0 + 0 +  0 + 0 + 2 + 1 => 195

1001 1000 => 128 + 0 + 0 + 16 + 8 + 0 + 0 + 0 => 152

-----

& : 합연산 -> 둘다 1일 때만 1;
1000 0000 이 됨.

-----

| : 곱연산 -> 둘다 0일 때만 0
1101 1011이 됨.

-----

1100 0011 에서 뒤에서 두번째 1만 제외하고 싶다면?

1100 0011과
1111 1101을 곱연산 시키면 됨. 즉, ~0000 0010을 합연산

A |(~0000 0010)을 하면 그 자릿수만 빠지게 되는 것.

---

1100 0011 에서 뒤에서 3번째 0을 1로 바꾸고 싶다면?
0000 0100을 곱연산 시키면 됨.

A | (0000 0100)을 하면 그자리만 추가되는 것.
