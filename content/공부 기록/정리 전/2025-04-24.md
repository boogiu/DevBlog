#수업기록 

오늘의 수업은 이미지 출력을 하게 됨.
비트맵을 출력하는 구조이기에 API에서만 사용하게 됨.


---

오늘의 메인 클래스
1) 비트맵 파일을 읽어들리는 클래스
2) 비트맵 매니저(싱글톤 클래스)

## 확장자 BMP
비트맵의 계층 : 파일 헤더 계층 / 인포 계층 /픽셀 계층 3가지 계층을 사용함.
(나중에 3D 가서 지형을 만들 때 비트맵을 사용하기도 함 - 디자이너가 메쉬를 만들어줄 수 없는 상황일 때)

API는 비트맵 이미지 출력 기반이다.
알파 채널이 존재하지 않기에 현 시대에서는 잘 사용하지 않게 됨.
(지금은 지원하지만, 용량이 커서 잘 쓰지 않는다.)


-----
화면의 DC를 복사해서 이미지 DC를 따로 생성해주어야 함.

이번 2차 과제 끝나면 API 시연회 준비 기간이 된다.
