==
의식의 흐름대로

새프로젝트 만들기 데스크톱 마법사.
폴던는 프레임워크 폴더에 만들어두고 프로젝트 이름은 클라이언트와 엔진으로 나누어서 할거임.

솔루션이름은 프레임워크
데스크톱애플리케이션으로 다른거 체크 안하고 생성.

이렇게 해서 클라이언트 프로젝트 만들었음.

폴더 관리부터 함.
각 프로젝트 별로 폴더 만들어서 관리할 것임.
이전과는 조금 다른긴 함.


폴더 바이너리/프라이빗/퍼블릭/디폴트 네개의 폴더로 관리할 것임.

디폴트 -> 프로젝트 생성 파일들을 옮겨줌.
바이너리 -> 실행 파일 / 리소스파일들 
프라이빗 ->CPP 파일 
퍼블릭 -> 헤더 파일

기본으로 만들어진 파일을 디폴트에 넣으면서 프로젝트 파일도 같이 옮겨짐.
프로젝트의 파일이 바뀌었기 떄문에 솔루션에서 다시 추가해줘야 함.
